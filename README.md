# cashbook
1. It is a Lightweight user-friendly web application designed for managing daily financial transaction.<br>
2. This tool helps to track "cash-in" and "cash-out" movements, and provide total balance and spending habits.<br>
3. Financial data is protected through personalised PIN.<br>
4. We can organize and view Transaction history by specific Months, Create Backup codes to move the data between devices or browsers.<br>
5. We can generate a printable version or save any particular cashbook as a pdf for offline records.<br>
6. It can store 20-25 account details about cash transaction. We can rename and Delete Cashbook after creation.<br>
